# 利用可能技術・制約条件

このファイルに開発時の技術的制約を記述してください。
/converge 実行時に自動的に読み込まれ、MVPスコープを現実的にするために使います。

## 記述例

### 利用可能な技術スタック
- フロントエンド: React, Next.js
- バックエンド: Node.js, Python
- インフラ: AWS (EC2, S3, RDS)
- CI/CD: GitHub Actions

### 制約
- 新規サーバー構築には情シス承認が必要（2週間程度）
- 外部SaaSの新規契約には稟議が必要
- エンジニアリソース: 週20時間まで（兼務のため）
- 本番デプロイは月1回（第3金曜日）
