# Priority Score ルブリック

BUILD / DEFER / KILL 判定に使うスコアリングルール。
組織の判断基準に合わせて編集できます。

## スコア定義

| Score | Verdict | 条件 |
|-------|---------|------|
| 5 | BUILD | 月間 20h 以上の削減 + ワークアラウンドが苦痛 + 3ヶ月放置で業務に支障 |
| 4 | BUILD | 月間 10〜19h の削減 + ワークアラウンドあり + 最小構成が明確 |
| 3 | DEFER | 月間 5〜9h + ワークアラウンドで当面回せる |
| 2 | DEFER | 月間 5h 未満 or 3ヶ月放置しても影響なし |
| 1 | KILL | なくても困らない or 既存ツールで代替可能 |

## 補正ルール

- 月間時間が不明な場合、スコアから 1 を引く（最低 1）
- 影響人数が不明な場合、ROI 計算では 1 人として扱う

## カスタマイズ例

- 時間の閾値を変更（小規模チームなら「月間 10h+」で BUILD 5 にする等）
- 条件を追加（「法令対応が必要」なら無条件で BUILD 5 にする等）
- Verdict を追加（「EXPERIMENT（小さく試す）」等）
