# Priority Score ルブリック

converge の BUILD / DEFER / KILL 判定に使用するスコアリングルール。
このファイルを編集することで、組織の判断基準をカスタマイズできます。

## スコア定義

| Score | Verdict | 条件 |
|-------|---------|------|
| 5 | BUILD | 月間20h以上 + ワークアラウンドが苦痛 + 3ヶ月放置で業務に支障 |
| 4 | BUILD | 月間10-19h + ワークアラウンドあり + 最小構成が明確 |
| 3 | DEFER | 月間5-9h + ワークアラウンドで当面回せる |
| 2 | DEFER | 月間5h未満 or 3ヶ月放置しても影響なし |
| 1 | KILL | 「なくても困らない」or 既存ツールで代替可能 |

## 補正ルール

- `monthly_hours_current: unknown` の場合、算出されたスコアから1を引く（最低1）
- `affected_users: unknown` の場合、ROI計算では1人として計算する

## カスタマイズ例

組織の状況に合わせて条件を変更できます:

- 時間の閾値を変更: 小規模チームなら「月間10h+」をBUILD 5に引き下げる
- 新しい条件を追加: 「法令対応が必要」なら無条件でBUILD 5にする
- Verdictを追加: 「EXPERIMENT（実験的に小さく試す）」を追加する
